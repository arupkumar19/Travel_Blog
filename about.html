About

The story behind the journal

Welcome to Anu-Arup Travel — a personal record of the places I have visited, the things I have seen, and the stories worth keeping. This site is organized by year, month, and destination, so every trip is easy to find later.

I travel to slow down, look properly, and come back with something to remember. This journal is that record — part photo album, part diary, part itinerary for anyone who wants to go to the same places.

Adding a New Trip

This site runs entirely from a single JSON file. No database or backend is needed.

  1. Create a folder for the trip's photos under assets/images/<year>/<month-destination>/.
  2. Add a cover photo (e.g. cover.jpg) and any gallery photos. Compress and resize images before committing to keep the repo lightweight.
  3. Open data/trips.json and add a new trip object at the top of the array. Copy an existing entry as a template and update every field.
  4. Set the correct coverImage path and add each photo to the photos array with a caption.
  5. If you have a video, paste the YouTube embed URL into the videos array.
  6. Preview locally: open a terminal in the project folder and run python3 -m http.server 8080, then open http://localhost:8080 in your browser.
  7. When everything looks right, commit your changes and push to GitHub. The site will update automatically on GitHub Pages.

Deployment

This site is hosted on GitHub Pages. After pushing to the repository, open Settings → Pages, select your branch and the root folder, then save. The published URL will be https://YOUR-USERNAME.github.io/travel-blog/.

Use relative asset paths such as assets/images/... throughout the JSON so photos load correctly under the repository's URL path.
